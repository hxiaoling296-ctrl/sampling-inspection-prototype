全部任务 / 共用列表

顶部筛选多选
所有下拉条件可勾选多个值；商品、主任务、子任务与相似品编码输入框可用逗号或空格分隔多个值。同一字段任一值命中，不同字段共同过滤。
页签
全部任务、待派单、确认接单中、已进单、待审核、款项确认；草稿、待派单、接单失败合并在待派单页签。
导出款项数据
全部任务页签仅导出当前筛选结果中已完成主任务的 CSV 或 Excel，每个检测项目一行；没有已完成订单时不可导出。
导入数据派单
全部任务和待派单页签提供入口，支持上传 CSV 或 Excel（.xlsx）。每行一个 SKU 的一个检测项目，同批次编号的多行合并为一个主任务，按 SKU 生成子任务；校验商品编码、抽检类型、任务类型、机构、审核人、寄样方式和项目后预览。确认后按本次机构派单，主子任务进入待接单，派单人记录当前操作人。重复批次编号不再次创建。
商品类目
全部任务、待派单、确认接单中、已进单、待审核和款项确认的主任务行只读展示商品类目；商品编码以 ry 开头归日用，以 SP 开头归食品，大小写均可。
筛选字段
商品编码或名称、主任务单号、子任务编码、相似品商品编码、抽检类型、主任务状态、子任务状态、抽检机构；编码支持模糊匹配，子任务状态与机构匹配任一子任务。
同品待完成任务
主任务单号后展示相同商品编码的其他未完成主任务单号；已完成及当前任务不显示。
任务类型 / 派单人 / 报告审核人
全部任务、待派单、确认接单中、已进单、待审核、款项确认列表展示主任务任务类型、派单人和报告审核人，派单人在审核人之前。派单人取确认派单时的当前操作人，重新派单时更新；历史任务没有记录则显示“未记录”。待审核页可改选审核人。
商品信息
点击商品展开主任务下全部子任务；显示执行标准、国抽分类、关联相似品、检测机构、检测项目汇总、状态与报告文件。主任务单号下不显示“确认接单中示例”标记。
任务状态
各状态使用固定颜色，同时保留文字；主任务与子任务分别显示状态。
删除主任务
全部任务列表中，草稿、待派单、接单失败、待接单、待采样、核样中的主任务显示删除入口。弹窗提示删除后不可恢复，请谨慎操作；二次确认后删除主任务及其所有子任务。已进单及之后的状态不显示删除入口。

创建抽检立项

商品编码
支持批量输入，每个商品生成一个草稿主任务；ry 开头的商品类目为日用，SP 开头的为食品。
抽检类型
每个商品分别选择：过会固抽、过会非固抽、专场抽检、上播抽检、历史遗留、上播盲测、商务提需、商家复检、二次抽检。
任务类型
每个商品创建时必选日播、专场、盲测、定制品或专项。
子任务生成
每个商品创建一个主任务，并默认用商品第一个 SKU 建立一个子任务；不再按执行标准数量拆分。草稿详情仍可手动新增子任务。

立项详情 · 商品与主任务信息

商品基本信息
顶部展示商品名称、商品类目、执行标准、品牌、商品图片；执行标准与主任务信息使用同一商品数据，所有任务状态只读展示。“查看全部商品信息”展示商品名称、商品类目、品牌、商品图片、供应商、售卖平台、店铺信息、参考链接、商品编码、标签、备注。补充售卖链接最多200字，授权成员输入后点击“确认修改”才保存；权限由系统预先按成员配置，无权限时字段只读且不显示按钮。
主任务信息字段
各状态统一展示款项确认状态的完整主任务字段集；原有编辑条件不变。采样金额、采样备注、进单日期和核样失败信息即使尚未产生也保留字段位置，无数据时留空。
主任务单号
一个商品对应一个主任务，作为下单主要识别对象；商品的全部执行标准在各页签主任务行和立项详情主任务信息中只读展示。
抽检事由
归入主任务信息，按主任务填写和保存。
任务类型
归入主任务信息，仅草稿和款项确认状态可修改，其他状态只读。
抽检类型
主任务信息中仅草稿和款项确认状态可修改，其他状态只读。
商品类型 / 费用支出方
归入主任务信息；费用支出方可选商家、与辉、二者皆有。确认接单阶段不可编辑。
抽检机构 / 派单人 / 报告审核人
首次派单时选择一家机构，可选填选择机构原由，同时从人员姓名中必选一位报告审核人；主任务信息展示本次机构、原由、派单人及审核人。派单人取确认派单时的当前操作人，不在详情中手动修改；接单失败后重新派单可改选机构并更新派单人。
寄样方式 / 派单备注
派单时必选商家寄样、机构采样或与辉寄样；派单备注可选，最多200字。两项保存后在主任务信息展示，重新派单时可调整。
采样订单图片
采样成功弹窗支持上传最多10张图片，保存后在立项详情主任务信息中展示并可预览。
采样金额 / 采样备注 / 核样失败信息
核样中及之后的主任务在采样金额后展示采样备注；款项确认时可修改费用支出方、采样金额、寄样方式和选择机构原由。核样失败后展示原因、是否退样成功、样品处理方式和必传的采样订单图片（最多10张）。

立项详情 · 子任务信息

子任务编号
待派单及确认接单中的任务可手动编辑；不能为空，且不可与任何已有子任务编号重复。
执行标准 / 国抽分类
执行标准为商品属性，子任务按立项 SKU 建立；国抽分类为可输入下拉框，列出截图中的粮食加工品、食用油及调味品分类选项，仍可输入其他分类。子任务未审核为报告合格或不合格且主任务未完成时，国抽分类和立项 SKU 可修改。折叠只收起关联执行标准至检测项目的内容，加急费用、检测机构与报价、报告和保存操作继续显示。
关联相似品
位于国抽分类下方，输入商品编码关联或移除后，须点击“确认关联”才保存。修改权限由系统按成员单独配置；无权限时只读，不展示关联和确认按钮。
立项 SKU / 附加物 / 商品外包装
立项 SKU 按商品固定选项选择，机构新增子任务在确认接单阶段也可选择；商品外包装移至主任务信息，点击更新保存。
检测项目 / 项目备注
点击获取检测项目不打开弹窗，按当前国抽分类直接补齐国抽项、与辉要求、宣称三个分组的分类示例项目；保留已有项目。每个检测项目下可填写项目备注，报价列表及报告审核弹窗展示该内容；审核弹窗还逐项目显示序号。子任务未审核为报告合格或不合格且主任务未完成时，检测项目可继续调整、新增、修改、删除。“新增检测项目”归入与辉要求。真实分类项目映射待替换。
费用金额
按子任务分别填写商家、与辉金额；可在派单后补充。
是否有加急费用
保留在子任务；子任务内不再选择检测机构或填写选择机构原由。
删除子任务
未出检测报告时可删除，删除前确认；已出报告时不可删除。

待派单

批量派单
勾选多个草稿、待派单或接单失败的主任务后点击“批量派单”。弹窗统一填写本次机构、报告审核人、选择机构原由、寄样方式和最多200字的派单备注；按所选机构逐主任务展示子任务检测项目汇总。无可派检测项目的主任务置灰跳过；可派任务分别记录当前操作人为派单人，主子任务进入待接单。接单失败任务展示原机构，本次可选择同一或其他机构。
主任务操作
全部任务和待派单列表均提供草稿主任务“派单”入口；待派单仍可删除草稿、待派单或接单失败的主任务，接单失败可重新选择本次派单机构。
派单
顶部“当前操作人”用于模拟登录成员，点击确认派单时记录为本轮派单人。每轮派单必选一位报告审核人、一家机构及寄样方式，选择机构原由可选填，可填最多200字的派单备注；重新派单带出上次内容并允许调整机构。弹窗“检测项目汇总”与列表展开行一样展示项目名称和数量；切换机构时按该机构可派项目更新汇总。仅派出有检测项目的子任务，费用信息不阻拦派单。详情中的派单按钮放在页面底部；派单后主子任务进入待接单。
检测机构 & 报价
草稿表只展示各机构参考报价，不展示实际报价和项目计算公式，保留原有列结构。展示项目类型、项目来源、项目计算公式及判定依据 / 限值的报价表，前三项排在判定依据 / 限值之后。派单选定机构后展示机构实际报价，默认等于参考报价，可输入非负且最多两位小数的金额；确认款项后只读。“本月接单数”按各机构本月已确认接单的主任务计数。待派单、待接单、待采样、核样中可修改和删除报价项目。

确认接单中

批量操作
先勾选主任务，再点击“批量操作”，从下拉列表选择确认接单、拒绝接单、采样成功、采样失败、核样成功、核样失败或采样并核样成功。弹窗列出所有已选任务：当前状态适用的可操作，其余置灰且本次跳过；采样成功及快捷进单逐任务填金额，核样成功及快捷进单逐子任务填预计完成的自然天数，核样失败逐任务填原因、后续状态、退样结果和样品处理方式。
接单操作
确认接单进入待采样；拒绝接单进入接单失败并返回待派单。
采样操作
采样成功输入金额，可选填最多200字的采样备注，确认后进入核样中；批量采样及采样并核样成功弹窗同样支持填写备注。采样失败返回待接单。
核样操作
点击核样成功先弹窗确认，逐子任务展示与列表一致的检测项目汇总，并填写预计完成时间：正整数自然天，提示“请输入自然天”，默认7天；确认后进入已进单。核样失败填写原因、退样结果和最多200字的样品处理方式，并选择保持核样中或退回待采样。
采样并核样成功
待采样或核样中可单任务或批量填写采样金额、逐子任务填写预计完成天数后直接进入已进单；不适用任务在批量弹窗置灰。
机构新增项目
与原项目并存，可填写独立参考报价，实际报价默认相同并可单独调整；项目内容不必与原立项项目一致，新增时必选合同内或合同外。机构项目列表展示项目类型、项目来源及项目计算公式。
机构新增子任务
已进单前可编辑立项 SKU、是否有加急费用、检测机构与报价；机构由主任务统一确定，其他字段在已进单后开放。
导入数据 / 导出
支持 CSV 和 Excel。导入匹配已有主子任务，更新状态、采样金额、机构检测项目及项目来源；导入机构必须与主任务派单机构一致。待采样或核样中可导入已进单状态直接完成采样及核样，“预计完成天数”按子任务填写，留空默认7天；导出当前筛选结果下的全部子任务及项目，报价区分参考报价和实际报价。

已进单

进单日期 / 退回
确认核样成功时记录当天为进单日期；已进单列表及详情显示。全部子任务尚未出报告时，点击退回并二次确认，主子任务回到核样中，同时清空进单日期、预计完成自然天数与预计完成日期。
上传报告 / 报告备注
主任务可批量按子任务上传，子任务可单独上传；每个子任务支持多份文件、替换和移除。每份报告可单独填写或修改最多200字的备注；立项详情按报告展示备注。
子任务报告状态 / 预计完成时间（自然天）
上传时选择已出但未出全或已出全；报告文件与状态分列展示。子任务展开列表和立项详情显示核样成功时逐子任务填写的预计完成自然天数；详情中在“检测机构 & 报价”下方展示报告。
上传限制
每个子任务只保留一个报告，弹窗直接点击报告旁的叉号移除；新文件替换旧报告。报告合格或报告不合格的子任务不可再上传报告。

待审核

展示条件
主任务已有报告时持续展示，直到点击确认审核完成；列表显示子任务关联相似品、报告审核人和进单日期，审核人可在本页重新选择。
预计完成时间
子任务列表及立项详情显示核样成功时填写的预计完成时间（自然天）；列表另展示预计完成日期及剩余自然天数，超期后标红。倒计时按自然日刷新。
审核弹窗
展示主任务进单日期，以及每个子任务的机构检测项目、项目备注、机构参考报价、机构实际报价与全部报告；逐份报告显示报告备注，PDF 和图片可预览。
商品标签 / 项目方法数量
报告审核弹窗顶部可编辑商品标签，关联同编码商品的其他主任务；报告审核和款项确认弹窗展示相同主任务信息、商品图片与下单图片。项目列表按检测方法分隔项统计数量，款项确认项目行增加序号。
审核备注
每个子任务可填研判备注和特殊情况备注；选择报告不合格时不合格备注必填，选择报告退回时退回备注必填，均最多200字。退回时保存当次报告和退回备注，重新上传后在审核弹窗仍可查看历史退回报告；上传弹窗展示退回备注。备注保存后在立项详情子任务底部展示。
审核状态
可设已出但未出全、已出全、报告合格、报告不合格、报告退回；报告退回后在确认接单中展示，可重新上传报告并选择已出但未出全或已出全，再进入待审核。报告合格或报告不合格后仍可再次审核并调整。所有子任务均为报告合格或报告不合格时才能点击确认审核完成；二次确认提示不可回退，确认后进入款项确认。

款项确认

主任务信息
列表及确认弹窗展示进单日期。确认弹窗在列表上方展示商品名称、商品编码、任务类型、抽检类型、抽检事由、寄样方式、费用支出方、派单备注、抽检机构和选择机构原由；其中任务类型、抽检类型、寄样方式、费用支出方可修改，点击“确认金额并完成”时保存，取消不保存。
项目来源
原立项检测项目默认为合同内；机构新增项目时必须选合同内或合同外，表格导入带入该字段。款项确认列表只读展示，不在此调整。
采样金额
立项详情与弹窗均可调整，必须为非负数且最多两位小数。
项目计算公式 / 项目备注
每个子任务检测项目逐行展示系统返回的只读计算公式及项目备注，原立项项目与机构新增项目均包含。
报价
列表同时展示机构参考报价与机构实际报价，保持与立项详情中的同名字段一致。
结算金额 / 费用合计
