抽检机构端

左侧“抽检机构端”下进入“抽检立项-机构”。与业务端共用筛选、主子任务列表和数据；派单机构按商品类目区分：食品7家、日用23家；机构端仅显示已派单给当前机构通标标准技术服务有限公司的主任务，页签为全部任务、确认接单中、已进单。机构端任务详情的子任务不展示捞回记录及报告审核备注；业务端仍展示。列表实现共用，同名页签的字段与布局同步更新。

页面与筛选

页签
业务端全部任务显示所有主任务；机构端全部任务仅显示已派单给机构的主任务。待派单显示草稿和接单失败；确认接单中显示待接单、待采样、核样中；已进单显示含已进单、逾期未出报告或报告退回子任务的已进单主任务；待审核显示有报告状态且尚未确认审核完成的已进单任务；款项确认显示待确认款项的款项确认和异常结束任务。
顶部筛选
商品编码、商品名称、相似品编码共用输入框；主任务和子任务单号支持模糊匹配；这三个文本筛选框输入多个值时可用逗号或空格分隔。抽检类型、商品类目、任务类型、主子任务状态、抽检机构、派单人、审核人、账期月份支持多选；任务类型可选日播、盲测、专场、专项、溯源，未选择时显示全部。进单日期、审核日期、计划出具报告日期各用一个起止日期筛选框；可记住筛选条件。全部任务和待审核可勾选主任务后批量修改报告审核人。
列表分页
业务端与机构端各页签的任务列表底部显示当前记录范围、总数、每页条数和页码。默认每页50条，可选3、5、10、20、50条；点击页码、上一页或下一页切换，筛选和切换页签后回到第一页。导出仍按当前筛选条件下的全部结果执行。
列表字段
主任务行显示商品名称与可复制编码、品牌、商品类目、标签、主任务单号、同品任务、任务类型、抽检类型、检测机构、寄样方式、派单人、派单日期、报告审核人、账期月份、进单日期、计划出具报告日期、子任务相似品、待出报告数量和状态。点击商品展开子任务，查看子任务单号、国抽分类、相似品编码、检测项目汇总、状态、计划出具报告日期、检测报告及其预览、审核日期。列表字段无数据时留空。
接单失败字段权限
接单失败主任务与草稿使用相同的字段编辑限制；原派单机构保留用于重新派单参考，检测机构报价区按派单前的多机构参考报价展示。
派单前的子任务状态
“待派单”仅为主任务状态；派单前的子任务显示草稿。未设置检测项目的子任务也显示草稿，不参与派单及后续接单、采样、上传报告、审核和结算；补充检测项目后才可进入对应流程。子任务状态中没有“待派单”或“无检测项目”。

创建与派单字段

商品与立项 SKU
批量输入商品编码，每个商品形成一个主任务；商品编码 SP 开头归食品，ry 开头归日用。每商品默认选择第一个 SKU，可多选；每个选中 SKU 对应一个子任务。最多添加100个商品编码，无效编码和超限数量在创建弹窗内提示。创建时先分配临时任务编号；确认派单后生成正式主任务及子任务编号。增删子任务后按剩余数量及顺序重编子任务号。
派单后任务编号
确认派单后，主任务单号为任务类型缩写（日播 RB、专场 ZC、专项 ZX、盲测 MC、溯源 SY）＋“-”＋商品类目（食品 SP、日用 RY）＋检测机构缩写＋派单日期 YYYYMMDD＋三位流水；费用支出方为商家时，在类目前加“F-”，日期取主任务创建日期。流水按商品大类（食品或日用）和实际派单日期分别从001递增，不复用；同一天同一大类的不同任务类型、机构和付款方共用序号。子任务单号为主任务单号＋“-”＋两位子任务总数＋“-”＋两位顺序号，例如 RB-SPH20261123001-03-01。接单失败重新派单后按本次机构与日期重新编号；表格导入派单也使用同一规则。
创建列表操作
创建抽检立项弹窗的商品列表将“操作”列放在计划专场、计划检测规格之后，位于列表最右侧；逐行“移除”按钮仍只移除对应商品行。
任务类型 / 抽检类型
任务类型为日播、盲测、专场、专项、溯源；抽检类型为过会固抽、过会非固抽、专场抽检、商务提需、客诉抽检、不合格复测、验厂抽检、上播盲测、上播抽检、中台比对、特殊抽检、年度复检。创建时可批量填入各商品行；草稿、接单失败、待接单及款项确认阶段可修改。
费用支出方 / 开票信息
费用支出方选商家、与辉、二者皆有；创建默认与辉，不合格复测默认商家。开票信息始终可填写，最多200字；选择商家或二者皆有时必填，选择与辉时可留空。接单失败可改费用支出方并重新派单；款项确认可调整。
商品类目
任务详情不展示抽检事由，主任务信息展示商品类型。商品类目为商品自带的食品或日用属性，不在立项时手动选择。
计划与派单信息
计划专场最多35字，计划检测规格最多100字。派单选一家机构、一个报告审核人和寄样方式（商家寄样、机构采样、与辉寄样）；选择机构原由可留空，派单备注最多200字。派单人取当前操作人，派单日期取确认派单日期。批量派单可先保存各任务设置而不改变状态；弹窗仅展示各主任务已有费用支出方，不提供修改入口，派单时按当前值校验。列表不展示“本次处理”列，可派单数量在表格上方汇总。
导入数据模板
仅“全部任务”页提供“导入数据派单”入口；下载提供的 Excel 模板，19个字段的表头逐项标明必填或选填；开票信息在费用支出方为商家或二者皆有时必填。按商品编码合并为主任务，按 SKU 建立子任务，每行对应一个检测项目，项目类型可填国抽、与辉要求、宣称项目。确认接单中提供与上传文件一致的17列 Excel 导入模板，含采样服务费及第二行状态说明；导出当前列表使用相同字段与列顺序，导入支持 Excel 或 CSV。

任务详情字段

基本信息 / 商品信息
基本信息平铺展示商品名称、商品编码、商品类目、品牌、执行标准、供应商、售卖平台、店铺信息、参考链接、补充售卖链接和商品图片，可整体收起或展开。执行标准只在基本信息中展示。主任务派单时锁定商品售卖规格、赠品信息和下单图片，点击各自“更新”按钮后立即从商品数据同步，仅更新当前主任务。两个字段分别展示更新时间，格式 YYYY-MM-DD hh:mm:ss。补充售卖链接最多200字，由授权成员单独确认修改。主任务信息首行依次展示主任务单号、任务类型和抽检类型，不重复展示商品名称、商品编码和品牌；在各状态保持同一字段布局，无值时留空，可收起字段区。
款项确认模块
任务详情中的款项确认模块可独立收起或展开，收起只隐藏金额与项目明细，其他模块保持原状；切换页面后保留当前任务的展开状态。项目明细依次展示项目计算公式、机构参考报价、机构实际报价和最终结算金额，报价与同名字段取值一致。
字段更新时间
任务详情的基本信息、主任务信息、报告与历史记录中可编辑字段，在成功修改后于对应字段旁展示最近更新时间，格式为 YYYY-MM-DD hh:mm:ss。未修改的字段不显示时间；报告退回记录展示退回时间。
账期月份
全部任务中的款项确认、已完成、已完成（异常）主任务可单条或勾选后批量设置账期月份，格式为YYYY-MM；各页主任务列表展示，顶部可按已有月份多选筛选。单条“添加/修改账期月份”弹窗只显示该主任务的“新账期月份”，不显示统一设置及批量提示。批量设置弹窗顶部选择账期月份后自动填入下方所有主任务的“新账期月份”列；可逐条调整，点击确认保存后才生效。批量修改审核人弹窗同样在顶部选择后自动填入下方所有主任务的“新报告审核人”列，可逐条调整，确认修改后生效。
进单 / 计划报告 / 审核日期
进单日期取核样成功或采样并核样成功日期。计划出具报告日期按子任务选择，超过日期仍未上传报告显示逾期未出报告。审核日期只在子任务行展示，取该子任务最近一次报告审核状态变更为审核完成或报告退回的日期；主任务行不展示审核日期。
主任务采样信息
采样金额与采样服务费为非负金额。服务费默认比例：通标、广州检验检测、华测、上海天祥、长春海关6%，欧陆8%；超过相应比例标红。款项确认前可调采样金额与服务费、采样备注及采样订单图片，图片最多10张。派单备注在款项确认前可改；更新时间统一为 YYYY-MM-DD hh:mm:ss。
商家寄样信息
商家确认接单时，可按子任务填写样品量（最多100字）和寄样地址（最多200字）；这两个字段展示在各子任务“检测机构&报价”列表下方，参与派单的任务在已进单前可逐个子任务输入并自动保存，修改后各字段显示自己的更新时间。主任务信息不展示这两个字段。
子任务国抽分类 / 相似品
子任务按立项 SKU 建立；顶部新增按钮在可操作状态下统一显示“手动新增子任务”。子任务单号只读、可复制。子任务立项字段和检测项目行修改后需点击该子任务的“保存子任务”按钮生效；离开详情前未保存的修改将撤销。国抽分类为必填，支持输入或下拉选择；子任务保存、派单及报告审核时校验。相似品按商品编码关联，授权成员点击确认后保存。子任务立项信息区域可单独收起，不影响下方报价与报告；执行标准仅在基本信息中展示。
原立项检测项目
按国抽分类获取国抽项、与辉要求、宣称项目，每个子任务最多获取3次。新增检测项目弹窗选择项目类型并填写检测项、检测方法、判定依据 / 限值和项目备注；检测项必填，其余文本字段与子任务项目行一致。三个分组的勾选和全选在草稿、接单失败可操作；原立项项目在这两个状态下按相同规则编辑。
机构检测项目与报价
机构新增项目与原项目并存，可按预置名称匹配并带出方法与依据；项目类型选国抽、与辉要求或宣称，来源为合同内或合同外。机构新增项目和修改检测机构项目弹窗字段一致：检测项目名称、检测方法、判定依据、判定依据 / 限值、项目类型、项目来源、项目备注、项目计算公式、机构附加物、机构参考报价及机构实际报价；判定依据紧跟检测方法，项目计算公式紧跟项目备注。机构附加物可不填，最多35字。机构参考报价和实际报价分列；草稿及接单失败状态下参考报价只读，修改项目名称时保留原参考报价。实际报价初始等于参考报价，进入款项确认或异常结束阶段后锁定。机构附加物随项目展示在报告审核和款项结算弹窗中。款项确认前可调整机构项目顺序及删除项目。
项目来源 / 计算公式
创建主任务时的检测项目默认为合同内；机构新增项目可填合同内或合同外，表格导入可带入项目来源。机构新增项目和修改检测机构项目弹窗中的项目计算公式为选填文本，位于项目备注下方；未填写时保存为空。已有项目的系统公式可带入修改弹窗。款项确认时只读展示项目公式。
报告与审核备注
每个子任务当前只保留一份报告，报告备注最多200字；当前报告及历史退回报告在任务详情中持续展示，PDF和图片文件可预览，报告备注与退回备注随文件展示。研判备注、特殊情况备注、不合格备注在详情中按独立成员权限分别保存；主任务已进单及之后可编辑。
删除子任务
主任务处于已进单之前的状态时可删除子任务。点击删除先提示不可恢复；最后一个子任务不可删除。确认时再次校验当前状态，状态不符则提示更新后重试并刷新页面；删除成功后按主任务单号、剩余子任务数量和顺序重新编号。
捞回记录
款项确认、已完成或已完成（异常）的主任务可捞回。弹窗多选子任务后，按子任务分别展示旧记录、捞回信息和上传图片或文件字段，并在“子任务状态”下拉框默认展示当前状态；可调整为待定、报告合格、报告不合格、内部比对、AB货、报告作废-合格、报告作废-不合格。每个选中子任务的捞回信息必填、最多200字；附件每个子任务最多10个，单个不超过10 MB。各子任务分别记录信息、状态变化、附件、操作人和时间，最新在上。

阶段操作与校验

确认接单与核样
待接单确认后为待采样，拒绝后为接单失败。采样成功填写金额、备注、服务费及订单图片；核样成功按子任务选择计划出具报告日期并记录进单日期。核样失败填写原因、是否退样成功、样品处理方式和图片，选择保持核样中或退回待采样；退回时清空原采样金额、服务费、备注及订单图片。
上传报告
已进单页可单个或批量上传。批量文件名以子任务单号开头即可自动归属，可在弹窗修改名称并统一选择已出但未出全或已出全。每个子任务只保留一份当前报告；已有报告先删除再上传，审核完成状态不可上传。
报告审核
审核弹窗在子任务名称后展示国抽分类，每个子任务模块可单独收起或展开；弹窗展示机构项目、报价、报告、历史退回与备注，支持预览。可选择待定、报告合格、报告不合格、内部比对、AB货、报告作废-合格、报告作废-不合格或报告退回；已出但未出全、已出全仅展示不可作为审核结果。报告不合格时不合格备注必填，报告退回时退回备注必填，均最多200字。所有子任务进入审核完成状态后，二次确认主任务审核完成，进入款项确认且不可回退。
款项确认
确认采样金额、采样服务费及有效检测项目的结算金额；项目计算公式只读，结算金额默认机构实际报价。费用合计等于采样金额＋采样服务费＋项目结算金额，各方需支付金额合计不得超过费用合计。异常结束任务的项目结算金额固定为0。确认后普通任务为已完成，异常任务为已完成（异常）。
导入与导出
创建派单、接单阶段数据可按页面入口用 CSV 或 Excel 导入。全部任务可按当前筛选以 Excel 导出已完成订单款项，以及不合格备注；款项数据导出沿用提供的28列 Excel 样式，包含开票信息、派单备注、采样服务费和附加物备注；附加物备注位于 R 列，取项目填写的机构附加物，未填写时为空，费用合计包含采样服务费，文件名为“款项数据-YYYY-MM-DD hh：mm：ss.xlsx”（Windows 使用全角冒号）。不合格备注导出沿用提供的9列 Excel 样式，新增审核人列，文件名为“不合格备注信息-YYYY-MM-DD hh：mm：ss.xlsx”（Windows 使用全角冒号）。确认接单中可导出当前主子任务数据。
